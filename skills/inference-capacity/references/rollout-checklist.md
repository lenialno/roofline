# Чеклист выкатки

```
Что выкатываем: <модель | версия движка | шаблон | флаг>
Профиль: <profiles/<new>.env>, порт <N>; старый профиль <old>, порт <M>
Версии: движок <x.y.z>, torch <...>, CUDA <...>, драйвер <...>, образ <digest>
Веса: sha256 проверены <да/нет>, safetensors, chat template из репозитория <да/нет>

Gate (все PASS, иначе не выкатываем):
  task health            <...>
  task smoke-toolcall    <...>
  task bench             ttft p95 <...> / baseline <...>; tpot p95 <...> / baseline <...>
  задачи агента          <N из M>, baseline <N из M>

Canary: <доля трафика>, <длительность>, метрики обеих реплик каждые 10 минут
Критерий отката: ошибки клиентов > 1%, ttft p95 или tpot p95 хуже baseline на 20%, smoke FAIL
Откат: трафик на порт <M>; task stop INFER_PROFILE=<new>
Полное переключение: <время>; старый профиль остановить <когда>
Журнал: запись в bench-журнал и профили
```
